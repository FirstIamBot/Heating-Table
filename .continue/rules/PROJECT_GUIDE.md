# АРХИТЕКТУРА И КАРТА ПРОЕКТА (ESP32 HEATING TABLE)

## 1. Аппаратная конфигурация (Hardware Mapping)
- **Контроллер**: ESP32
- **Датчик температуры**: Термопара MAX6675 (`CLK`=13, `CS`=12, `DO`=14). Обновление раз в 1000мс.
- **Нагреватель (Силовая часть)**: Диммер RBDdimmer (`OUTPUT_PIN`=25, `ZEROCROSS`=26). Режим работы: `NORMAL_MODE`.
- **Органы управления**: Энкодер `AiEsp32RotaryEncoder` (`A`=1, `B`=3, `BUTTON`=15). По шагам: 4 шага на щелчок.
- **Дисплей**: OLED `Adafruit_SSD1306` (I2C: `SDA`=5, `SCL`=4), разрешение 128x64.

## 2. Состояния и Режимы работы (Конечный автомат)
Регуляция выполняется через битовые маски переменных `Mode` и `State`.

### Переменная `Mode` (Режимы работы стола):
- `MODE_FLAG_STANDBAY` (0) — Режим ожидания. Нагреватель выключен.
- `MODE_FLAG_MANUAL_HEATING` (1) — Ручной режим. Температура задается энкодером.
- `MODE_FLAG_PROG_HEATING` (2) — Программный термопрофиль.
- `MODE_FLAG_TEST` (4) — Тестовый режим для калибровки PID.
- `MODE_FLAG_SnPb` (8) — Суб-флаг программного режима: свинцовый припой (Профиль 0).
- `MODE_FLAG_PbFree` (16) — Суб-флаг программного режима: безсвинцовый припой (Профиль 1).

### Переменная `State` (Статус регулятора):
- `STATUS_FLAG_HEATING` (1) — Нагреватель физически активен, PID вычисляется.
- `STATUS_FLAG_CUR_MES` (2) — Переключение OLED: 1 — отображать уставку, 0 — измеряемую температуру.
- `STATUS_FLAG_Tracking` (4) — Режим точного удержания (активируется в зоне `switchTemp`).

## 3. Логика Двухзонного PID (QuickPID)
- Используется адаптивный PID (`TableHeatPID`).
- **Разгонная зона**: Если `deltaTemp > switchTemp`, используются базовые коэффициенты `Kp, Ki, Kd`, лимиты мощности `0..100%`.
- **Зона удержания (Tracking)**: Если температура подходит к уставке снизу (`0 < deltaTemp <= switchTemp`), при `twoZonePID == 1` включаются коэффициенты `KpTracking, KiTracking, KdTracking`. Лимиты мощности сужаются до `minimize..100%`, предотвращая просадку инерционного стола.
